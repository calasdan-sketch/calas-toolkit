## 📋 Notes

- **Private repos** (lead-me, calas-reception, watchpost, watchpost-agent, calas-security-suite, OBLITERATUS, system_prompts_leaks + the security mirrors) need the PC's git credentials to clone.
- **Heavy forks** (ghidra, OpenHands, activepieces, univer…) are large; left on GitHub to save disk. Clone on demand with `git clone --depth 1 https://github.com/calasdan-sketch/<repo>.git`.
- `ventures` is the local monorepo (Quote Me lives at `ventures/apps/sitequote`); `calas-factory` is a local-only working repo with no GitHub remote.
